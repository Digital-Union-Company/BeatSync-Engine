## Fork-specific code (`src/beatsync_fork/`)

All Digital Union additions live in this package. Upstream never creates this directory, so features
land here with almost no merge-conflict surface; upstream modules are touched only at small call sites
marked `# [FORK]`. Grep for `[FORK]` to enumerate the entire divergence surface.

**Hard rule:** nothing in `beatsync_fork` may import the upstream runtime (`logger`, `paths`, `gradio`,
`cupy`, `cv2`, `librosa`, `numpy`). `logger` imports librosa at module scope and mutates
`PATH`/`CUDA_PATH`, and importing `paths` creates directories as a side effect — depending on either
would make the fork package untestable on a bare interpreter. `tests/test_no_runtime_dependency.py`
enforces this both dynamically (subprocess module-table check) and statically (AST import inspection).

| `progress_view.py` | `ProgressView` — folds events into the status panel text |
| `qwen_progress.py` | Qwen worker stdout protocol + translator + the streaming `Popen` runner |
| `qwen_partials.py` | Stage-5 A1: the per-job partial artifact the Qwen worker publishes after each job's loop returns. Owns `PARTIAL_CONTRACT_VERSION` (a **transport-artifact** version, deliberately not coupled to `CACHE_CONTRACT_VERSION` — it reaches no cache key, signature or record), the sibling filename formula (`{response_stem}_job_{index:05d}_{safe_job_id}.partial.json`, reusing the worker's own `_response_prefix` convention), the anchored discovery glob that excludes `mkstemp` leftovers, the payload builder and the atomic writer (unique same-directory temp → `fsync` → `os.replace`, the `_save_cache` shape). A partial carries `semantics`/`timings` **verbatim** and **no verdict**: `_qwen_job_completed` and `_cache_entry_is_complete` stay the only completion rules, in `video_analysis.py`. `job_total` and `backend` are diagnostic only, and backend values vary within a batch (`load_seconds` accumulates, `batch_size` is reassigned by a slot restart) so a reader must take them from the **last** valid partial. Mints no identity, reads no clock, deletes nothing but its own temp. Since **A2-S1** it also owns the read side: `find_partials` (the `partial_glob` pattern applied with `os.listdir`, so `video_analysis.py` stays free of the directory enumeration its "no cache sweeper" guard bans — deliberately no `glob`/`fnmatch` import, neither being on this package's stdlib allowlist) and `load_partial`, which verifies a JSON object, a known `PARTIAL_CONTRACT_VERSION` and the caller's expected `invocation`, returns a mapping or `None`, and never raises. The reader answers *"is this a well-formed partial of this invocation?"* and nothing more: job/source authority and every completion decision stay in `video_analysis.py`. **A1 was inert; A2-S1 made it conditionally consumed** — the final response is still primary, partials are fallback evidence only when it is unusable, recovery is same-invocation only, and there is still no cross-run resumability and no durability guarantee |
| `ffmpeg_diagnostics.py` | bounded, vendor-neutral summaries of FFmpeg stderr for failed clips |
| `variation.py` | creative variation seed: normalisation + the seeded top-K selection rule |
| `creative.py` | the resolved `CreativeProfile`: seven controls, their normalisation and their mappings (seed handling delegated to `variation.py`) |
| `presets.py` | the four named Creative Preset recipes: immutable data plus three total helpers. UI-only — the name reaches no stage, no profile and no cache |
| `freestyle.py` | Freestyle V1: per-**section** creative rules. Owns `FREESTYLE_CONTROL_FIELDS` (the six controls minus `micro_cuts`, **derived** from `presets.CREATIVE_CONTROL_FIELDS`), the ten-entry Stage-3 section vocabulary, the frozen deepcopy-safe `SectionOverride` / `FreestyleDeclaration`, the preset→numbers projection, the sparse `effective_profile` composition and the one truthful summary formatter. The Variation Seed and Micro Cuts are **absent by construction** — there is no field for either, so a rule cannot touch them. Depends on `creative.py` and `presets.py` only; it is the **only** fork module restating an upstream vocabulary, and that tuple is pinned against the real `stage3_sections.py` by test. Renders nothing, analyses nothing, caches nothing |
| `creative_recipe.py` | the seven-integer `CreativeRecipe`: the exact resolved **visual** creative configuration for one render (Variation Seed + the six creative controls), strictly validated as a whole, bridged to `CreativeProfile`. Complete for the visual interpretation it stands for — **not** for the whole physical render: E2's three generated audio levels are the sibling `AudioRecipe` in `variant_lab.py`, never a field here and never routed through `CreativeProfile` |
| `variant_lab.py` | Variant Lab: named stable RNG sub-streams (`clips`, `controls` and, since E2, `audio`), the frozen spread formula, range/config normalisation, and one Generate resolving a visual `CreativeRecipe` **plus** a sibling `AudioRecipe` from one shared master seed and one shared Spread. It resolves; it renders nothing |
| `variant_batch.py` | Variant Lab C3 V1: multi-variant generation and comparison. Derives one candidate master per index under the `batch` RNG domain, then calls `variant_lab`'s frozen `resolve` / `resolve_audio` **unchanged** — it orchestrates, it never re-implements. Owns the candidate-count bounds, the deepcopy-safe `VariantBatchDeclaration` / `VariantCandidate` / `VariantBatch` session records and the one comparison-table formatter. Depends on `variant_lab`; `variant_lab` must never depend on it. Renders nothing |
| `render_batch.py` | Variant Lab C3-R0 → C3-R1B-b: rendering **2–4** compared candidates. Owns the selection contract (`RENDER_SELECTION_MIN = 2` / `RENDER_SELECTION_MAX = 4`, canonical ascending index, duplicates and over-long selections **refused** rather than truncated — there is no `RENDER_SELECTION_SIZE`), the candidate output identity (index + master + request tag — never the Variation Seed, whose uniqueness C3 does not guarantee), and the batch outcome/summary model. Pure: it decides, `gui.py` performs every side effect. No Gradio, no filesystem, no clock, no randomness, no renderer. Since C3-R1A each candidate outcome carries a typed `outcome_kind` validated against `success` in `__post_init__`; since C3-R1B-b the batch-level cause is restricted to `None`/`CANCELLED`/`SHARED_FATAL`/`UNKNOWN_FATAL` and only `SHARED_FATAL`/`UNKNOWN_FATAL` may be named as the candidate that stopped the run. It **records** causes and still **performs** nothing: no `threading`, no `Event`, no `terminate`/`kill`, no `Popen`, and no continuation policy — `gui.py` alone consumes the typed cause to decide whether to carry on. Its one fork dependency is `render_worker` |
| `render_worker.py` | C3-R1A: the pure render-lifecycle / cancellation contract. `RenderCancelled` (an ordinary `Exception`, never `BaseException`, so every broad catch on the render path must name it explicitly), `RenderOutcomeKind`, `RenderLifecycleState` with its monotonic `_ALLOWED_TRANSITIONS` table, the frozen `RenderOutcome`, and `RenderLifecycle` — one cancellation `Event`, one lock-protected state machine, one opaque invocation id. Owns **no** Gradio object, path, `Popen`, FFmpeg command, Qwen process, stage data, media or cache identity, and no registry of lifecycles. Terminal states accept no further transition and `_transition` silently no-ops once terminal, which is load-bearing for the batch's shared lifecycle. Decides *that* cancellation was requested; never *when* it is observed — that is each caller's safe-boundary choice |
| `audio_mix.py` | Audio Layers V1: `AudioMixConfig`, deterministic voice placement and the duck model. Pure — no FFmpeg, no probing, no filesystem |
| `smart_mix.py` | Smart Mix V1: the five SFX roles, the exact folder-alias table, `SmartMixConfig`, the Amount mapping, a stdlib percentile, all five placement rules and the cross-role occupancy policy. Pure — no FFmpeg, no probing, no filesystem walking, no numpy |
| `deterministic_view.py` | reconstructs a candidate's pre-Qwen deterministic scores from the raw CV primitives Stage 5 never fuses |
| `library_prep.py` | media library preparation: classification vocabulary, scan state, report text, bounded analysis batches (trackless since P2) |
| `director.py` | AI Director V2: the pure stdlib-only Director **semantic-intent boundary**. Owns `SEMANTIC_AXES` — the six *model-facing* editing dimensions, each with its own direction pair — and the model-facing JSON schema and prompts built from it, in which **none of the six execution control names may appear** (an import-time assertion and a permanent test both enforce that; it is the whole architectural distinction V2 rests on). Also the strict whole-stdout parser, the frozen `SemanticAxisRequest` / `SemanticIntent` records, the deterministic semantic→six-control mapping (`magnitude_for_strength` is integer half-up, never `round()`), the tolerant explanation policy, and the frozen deepcopy-safe `DirectorProposal` carrying **both** BASE and FINAL recipes plus an optional `MediaAdjustment`. **No subprocess, no model runtime, no media** — and no model path, no clock and no randomness either: `gui.py` runs the bounded one-shot invocation and mints the Variation Seed through the existing `variation.random_seed()`. A second *producer* of `CreativeRecipe`, never a second interpretation of one; it reuses `creative_recipe.from_mapping` unmodified as its trust boundary, for BASE and FINAL alike. Renders nothing |
| `director_media.py` | Director V2's **one** narrow media-aware adaptation: `source_diversity`, in the **diverse direction only** (`BASE > 50`), from prepared-library effective-source concentration. Owns `SUPPORT_FLOOR = 0.20`, `EFFECTIVE_SOURCES_FULL = 24.0`, the one support function, the explicit `half_up`, the frozen `MediaAdjustment` provenance record and the attenuation itself, whose `50 <= FINAL <= BASE` invariant is asserted rather than hoped for. Three further adapters were prototyped and **measured as not worth shipping** (Semantic Emphasis is execution-inert without Qwen coverage; Energy Response changed the sign of its benefit with the request direction; Motion Bias traded most of the requested character for noise), so their support inputs are deliberately absent — a test pins that they did not arrive as dead weight. Depends on `library_prep` for the facts record and on `creative`/`presets` for the one control registry; pure stdlib otherwise, with no filesystem, cache, model runtime, clock or randomness |
| `stage_cache.py` | L2 V1 process-local post-Stage-3 audio-analysis cache: one most-recent entry, strong track/window/config/use_gpu identity, defensive-copy isolation, no persistence; Stage 4/5/6 remain outside the cache |
| `collision.py` | R8 UX Refresh: what to do when a destination filename is already taken, as **one** rule both review workflows share. Owns the two policy strings (`SKIP` is the default and the pre-R8 behaviour; `SUFFIX` is opt-in), the total `resolve_policy`, the candidate sequence (`clip.wav` → `clip_01.wav` → …, extension preserved exactly) and the retry loop. **The rename is the authority, never an `exists()` check**: `publish()` takes the caller's no-replace rename as an argument and advances only when that call reports the name taken, so there is no check-then-act window — the module contains no `os.path.exists`, `os.stat`, `listdir` or `scandir`, pinned by test. `NoFreeName.attempts` is the signal callers branch on (never the policy they passed), because `attempts == 1` is the plain taken-name case and reusing each caller's existing wording for it is what keeps the default policy's operator-visible behaviour byte-identical. Deletes, copies and overwrites nothing: the only mutation is the injected rename, and `os.replace` appears nowhere. Pure apart from that one call, so every branch is testable without a disk |
| `cache_admin.py` | R8 UX Refresh: inspecting and clearing the application's own caches. **Discovers nothing** — every root is handed in by `gui.py`'s `_cache_categories()`, and every path acted on is proven inside that root by `realpath` + `commonpath` (never a string prefix, so `output-old/` is not part of `output/`), which is what enforces the never-delete list by construction rather than by a blocklist. Owns the four category keys, the `Category`/`Measurement`/`ClearOutcome` records, decimal `format_bytes`, the measurement walk and the clear. Two measured hazards are handled explicitly: `os.walk` **descends an NTFS junction**, so reparse-point entries are pruned from `dirnames` in place with `followlinks=False`; and a file an active job holds open is **reported and kept**, with its parent folders kept alive because only *empty* directories are pruned via `os.rmdir` — there is no `shutil.rmtree` anywhere. The root itself is never removed, a missing root is a first run rather than a fault, and `expensive` separates the Stage-5 analysis cache (a GPU/Qwen pass) from a poster that costs one frame grab. No clock, no randomness, no Gradio |
